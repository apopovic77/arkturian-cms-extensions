How to Use

Include the Stripe Checkout extension from CDN:

<script src="https://cdn.arkturian.com/stripe-checkout.umd.js"></script>

Initialize and create buy buttons:

const checkout = window.ArkturianCMS.StripeCheckout.init({
  publishableKey: 'pk_test_YOUR_KEY',
  apiEndpoint: 'https://api.../create-checkout-session'
});

checkout.createBuyButton(container, {
  id: 'product-1',
  name: 'Product Name',
  price: 9900,
  quantity: 1
});
